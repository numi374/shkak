Claude Sonnet 5.5：主力模型开始承担旗舰模型的工作

发布：2026-09-28Coding / Agent$2 输入 / $10 输出（每百万 Token）

这次更值得关注的不是“又提高了多少分”，而是 Anthropic 将 Sonnet 进一步放到大量日常 Agent、Coding、文档和企业知识工作的主力位置。对实际产品而言，模型路由开始比“永远使用最强模型”更重要。

怎么理解它的成本

任务成本 ≠ 单次 API 单价 任务成本 = 模型调用次数 + 输入/输出 Token + Tool Loop + Retry

因此便宜的 Token 单价不保证整个 Agent 任务更便宜。高推理模式如果生成大量推理 Token，最终成本仍可能上升。

什么时候用 Sonnet，什么时候用更强模型？

任务更合理的选择
Bug 修复、明确的小功能、批量处理Sonnet 级主力模型
复杂架构、大型迁移、开放式研究更强旗舰模型
值得记住：以后比较 AI 模型，最好比较“完成 100 个真实任务的总成本”，而不只是每百万 Token 的价格。

NVIDIA Open Agent Safety Platform：不要让 Agent 自己看守自己

发布：2026-09-28Agent SecurityOpenShell + Sentry

平台把安全边界拆成软件和硬件两层。OpenShell 管文件、网络、进程和 Credential；Sentry 则尝试在 Agent 所在软件环境之外监控越权行为。

Agent ↓ Sandbox / Policy ↓ Filesystem · Network · Credentials ↓ Hardware Watchdog

这里的核心思想是：Prompt 中写“不要读取私人文件”并不是权限控制。真正的权限应该在模型之外强制执行。

最适合的场景

Coding Agent、长期运行 Agent、拥有 API Key 的自动化、企业内部 Agent。普通的文章总结或简单聊天则没有必要部署这么重的安全层。

GitHub 开源深度拆解

项目：NVIDIA OpenShell · Agent 的最小权限运行环境

OpenShell 到底处于 Agent 技术栈的哪一层？

Claude Code / Codex / Copilot CLI ↓ OpenShell ↓ Operating System

它不是另一个 Agent，而是给 Agent 提供受控运行环境。核心价值是让“允许什么”成为可执行 Policy，而不是一句提示词。

四类关键权限

权限例子
Filesystem允许 /workspace，禁止 ~/.ssh
Network允许 GET api.github.com，禁止未经批准的 POST
Process限制危险系统调用与提权
Credential凭据在请求符合 Policy 时才注入

官方安装思路

curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh openshell status openshell sandbox create --name demo

Windows 当前更适合通过 WSL2 尝试，原生 Windows 并不是主要支持路径。实际使用前仍应核对项目当前 README，因为该项目处于快速开发阶段。

15 分钟理解实验

allowed_actions = ["read_note", "read_weather"] action = input("Agent 想执行什么？") if action in allowed_actions: print("ALLOW") else: print("DENY")

这里最重要的不是 Python 语法，而是 Default Deny：没有明确允许的能力，默认拒绝。

AI 产品实验室

原创产品假设：PermissionLens

让普通用户真正看懂 Agent 权限

今天大多数权限界面告诉用户“Agent 要读取邮件、联系人、文件”，却很少解释这些权限组合后究竟意味着什么。

READ FILES + NETWORK POST ↓ Agent 技术上可能把文件内容发送到互联网

PermissionLens 的目标不是替用户判断 Agent 一定会做坏事，而是明确区分 CAN 与 WILL：告诉用户“它具备什么能力”，而不是声称“它一定会这么做”。

MVP

功能第一版
读取 JSON / YAML Policy✓
解释权限组合✓
数据流图✓
修改并保存 Policy✓
自动批准权限✗

技术结构

Policy JSON/YAML ↓ Python Parser ↓ Rule Engine ↓ Risk Analyzer ↓ Human-readable UI

风险等级最好由确定性的规则引擎计算，LLM 只负责把技术描述翻译成人话。否则会变成“用另一个可能犯错的 AI 判断第一个 AI 是否危险”。

立即可做的 15 分钟实验

permissions = ["read_files", "network_post"] if "read_files" in permissions and "network_post" in permissions: print("风险：Agent 可以读取文件并向网络发送数据。")
